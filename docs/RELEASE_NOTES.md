# v0.1.0 发行说明与核验状态

## 当前地位

- 名称：LLM-Wiki-Literature。
- 本目录为初版 GitHub 发布准备副本的程序与手册。
- 自有代码、手册、全景图与合成样例采用 [MIT](../LICENSE)。
- 第三方组件保留各自许可；不能用项目 MIT 替代组件许可。

- 当前材料先完成本地发布审核与出包；实际公开状态以 GitHub 仓库及 Release 为准。

## 首版支持范围

- Windows 64 位、自己的 Codex、必需 Obsidian 与随包运行环境。
- 普通文字层 PDF 的单篇完整处理、独立检查、本地保存与阅读。
- 每篇最多 60 页、25 MiB，固定最多 60 分钟。
- 特殊页、OCR、批量、跨会话续作、其他 AI、跨平台和自动升级留到后续。
