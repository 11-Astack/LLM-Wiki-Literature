# 文献来源与 Firecrawl

## 从一篇本地 PDF 开始

本地处理流程不需要下载服务或账号。
先从你有权使用的渠道取得 PDF，核对题名、作者、年份、DOI 或 arXiv ID，
确认是目标版本，再把准确路径交给 Codex。

常见渠道包括出版方的全文页面、作者主页、机构仓储和 arXiv。
DOI 或元数据页面可能只有摘要；网页、链接和 Markdown 不能替代原始 PDF。
保留来源页面、取得日期与版本，不用新下载文件覆盖旧原件。

下载成功之后，仍需核身份、页数、文字层、全部图与公式，
再走本包逐页处理、独立检查和保存流程。

## Firecrawl 的位置

- Firecrawl 是独立的网页搜索和内容提取工具，可以辅助寻找公开页面与文件链接。
- 它是可选工具，首版没有接入命令，也没有自动文献下载或整站抓取流程。
- 不需要注册 Firecrawl 账号或填写 Key，才能使用本包的本地 PDF 流程。
- 查询或获取资料需要本次明确联网授权；工具能力不替代访问权限。
- 抓取的网页文本不证明 PDF 的页、公式、图和全文完整。
- 不上传本地 PDF、笔记或库；若另用外部服务处理文件，需要单独确认上传范围。
- Key、带凭据 URL 和个人登录信息不写进手册、示例或公共配置。

想了解可选工具时，阅读 [Firecrawl 官方文档](https://docs.firecrawl.dev/)。
此链接只是进一步阅读入口，本包不依赖其当前服务计划、价格或 API。

## 获准后怎样用获取工具

1. 只按公开题名或 DOI 搜索，先找到出版方、作者或仓储的落地页。
2. 核对目标文献与版本，确认有合法可取得的公开 PDF 链接。
3. 取得明确下载授权后，保存原始 PDF 和来源页面、日期、版本记录。
4. 把本地 PDF 交给本包；继续逐页核对、翻译与独立检查。

Firecrawl 的 [Search](https://docs.firecrawl.dev/features/search) 用于找页面，
[Scrape](https://docs.firecrawl.dev/features/scrape) 提取网页或公开 PDF URL 的内容为 Markdown。
这类提取结果不能当作下载保真的原 PDF，也不能代替本包逐页核对。
本包不执行这些外部命令，不接 API。

可复制下面的限范围请求，先授权公开资料查询，不自动下载：

> 本次只允许按［公开题名或 DOI］查询公开落地页和合法 PDF 链接。
> 请核对目标版本，给我来源与候选链接，等我确认后再下载指定文件。
> 不上传我的本地 PDF、笔记或库，不读取账号配置，不沿网站批量抓取。
> 取得原 PDF 后保存来源记录，再交给本包的本地流程。

## 隐私与分发

资料获取与本地处理是两个独立步骤。
授权查询公开网页，不等于授权上传自己的 PDF 或整个文献库。
本地保存也不等于 AI 完全离线：交给自己的 Codex 阅读前，
确认账号与产品数据设置符合你对这份材料的要求。

软件公共包只含程序、环境、手册和合成样例。
真实文献与自己的译文、笔记、Idea 和任务记录留在个人实例中。
准备公开真实资料时，应另行核对每份资料的许可和具体发布授权。
